# 运行模式契约

Nora 使用 `NORA_MODE`（服务端）和 `NEXT_PUBLIC_NORA_MODE`（前端）区分三个显式模式。

| 模式 | 数据来源 | 本地业务写入 | Mock 回退 | 审计身份 |
| --- | --- | --- | --- | --- |
| `demo` | API 或演示数据 | 允许，仅限浏览器演示状态 | 允许且必须标识 | 可使用“演示用户” |
| `development` | 本地 API/数据库 | 禁止伪造成功 | 禁止 | 开发环境身份，仅用于本地调试 |
| `production` | 生产 API/数据库 | 禁止 | 禁止 | 必须由真实认证上下文提供 |

## 开发环境演示预览

开发环境页头提供显式“演示全部页面”开关。开启后，当前浏览器会话临时进入隔离的 `demo` 数据集，用于浏览尚未接入正式服务的页面和交互；退出后重新从本地 API 加载 development 数据。

- 预览不会改变服务端 `NORA_MODE`，也不会把演示数据写入 development 持久化键；只在当前标签页的 session storage 保存开关，以便刷新和直接打开深层页面时保持演示身份。
- 演示批次使用 `DEMO-` 编号且只存在于浏览器会话，不调用正式写接口。
- production 不显示该开关，也不能通过状态动作开启预览。

## 不变量

- 缺省模式为 `development`，不是 `demo`。
- 生产模式缺少认证身份时，写操作失败；不得生成“演示用户”或“系统管理员”。
- 非演示模式 API 离线时展示不可用状态，不使用浏览器 Mock 数据继续工作。
- 本地持久化键按模式隔离，演示数据不得渗入开发/生产模式。
- 静态预测、模拟扫码和数字孪生样例必须有可见的“演示”标识。
