# Documentation Local Rules

继承仓库根 [AGENTS.md](../AGENTS.md)。文档用于保存稳定事实与决策，不用于复制过期实现说明。

- 产品边界放 `product/`；术语/流程放 `domain/`；生命周期放 `state-machines/`；跨方案决策放 `decisions/`；可执行结构放 `contracts/`。
- 原始会议纪要、表格和原型是输入材料，优先级低于测试、约束、已接受 ADR 和当前契约。
- 每个 ADR 写背景、决策、后果、验证及恢复/迁移；未决事项明确负责人类型，不替人决定。
- API、数据库、事件或状态转换变更必须同步更新对应文档。
- 链接使用仓库相对路径并通过 `pnpm docs:check`；不要链接本机绝对路径。
- 文档面向产品、工程与测试共同阅读，使用统一术语并提供真实业务样例。
