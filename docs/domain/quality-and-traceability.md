# 质量与追溯

## 质量对象

质量检查应绑定可追溯对象：采购收货批次、生产工单、生产批次、库存批次或出库批次。检查包含标准版本、样本、测量值、判定、操作者、时间和附件引用。

## 状态与处置

- 待检：不能被默认视为合格。
- 合格/放行：由有权限的真实用户确认。
- 不合格：进入隔离，并记录返工、降级、报废或让步接收。
- 撤销判定：不覆盖原记录，追加撤销与新判定。

## 追溯查询

向后追溯：成品批次 → 工单/生产批次 → 领用原料批次 → 供应来源。

向前追溯：原料批次 → 被哪些工单消耗 → 形成哪些成品批次 → 发往哪些订单/客户。

## 标准对齐

事件模型计划在语义上对齐 GS1 EPCIS 的 what/when/where/why 维度，但首阶段不宣称完成 EPCIS 认证或完整实现。

## 当前实现

首个工单质量切片以 `WorkOrderOutput` 为受检对象。检查追加保存现场使用的标准版本、抽样数量、实测温度、外观/封口/标签结果、判定、真实操作者、工位、设备和服务端时间。温度上下限来自报产时复制的工单冻结 v2 配方末道工序，不读取最新主数据。

合格放行与成品入库、工单完工在同一事务中完成；不合格批次不入库并进入工单异常。完整质量标准主数据、附件、撤销判定、复检、让步接收、采购来料质检和召回仍未实现。
