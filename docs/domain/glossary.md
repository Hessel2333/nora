# 统一术语表

| 中文 | 英文/代码名 | 定义 | 不应混用 |
| --- | --- | --- | --- |
| 产品 | Product | 可销售、采购、生产或库存管理的业务对象 | SKU、配方版本 |
| 配方 | BOM / Recipe | 某产品的结构定义；业务上用“生产配方”，代码沿用 `Bom` | 工艺路线、历史快照 |
| 配方版本 | BomVersion | 带版本号和生效区间的不可变发布单元 | 直接覆盖旧版本 |
| 配方快照 | RecipeSnapshot | 订单审批时递归冻结的完整多层配方事实 | 只存顶层版本 ID |
| 工艺路线 | Routing | 产品经过的工序及顺序 | 配方物料结构 |
| 销售订单 | SalesOrder | 客户在指定交付时间和地点的产品需求 | 生产工单 |
| 订单行 | SalesOrderLine | 产品、数量、单位和交付要求 | 物料需求行 |
| 生产需求 | ProductionDemand | 从已审批订单派生、供计划使用的需求事实 | 已排产批次 |
| 生产批次 | ProductionBatch | 针对产品、数量和日期形成的计划/执行批次 | 库存批次 |
| 工单 | WorkOrder | 面向工序或工作中心的可执行任务 | 销售订单、生产需求 |
| 库存批次 | Lot | 同源、同生产/采购事件的一组可追溯库存 | 生产批次编号可关联但不等同 |
| 库存台账 | InventoryLedger | 所有库存增减的追加式事实记录 | 可直接修改的“当前库存”字段 |
| 质量检查 | QualityInspection | 绑定批次、工单或收发事件的检查记录 | 只展示在大屏上的状态 |
| 演示模式 | Demo mode | 允许显式 Mock 和本地交互的隔离环境 | 生产模式回退方案 |
| 生产模式 | Production mode | 只接受后端事实和真实身份的运行环境 | 线上环境中静默使用 Mock |

## 语言原则

- 面向用户优先使用“生产配方”，技术文档可同时标注 BOM。
- “AI”仅用于存在真实模型/求解器、输入、版本、运行记录和可解释输出的能力。
- “实时”仅用于有明确刷新机制、数据来源和延迟定义的状态。
