# ADR-0003：演示、开发、生产模式隔离

状态：已接受
日期：2026-08-18

## 背景

原型为了可演示曾在 API 离线时写入浏览器 Mock 数据，并使用固定“演示用户”。如果该行为进入真实环境，会制造不存在的业务成功和不可审计身份。

## 决策

- 引入 `demo`、`development`、`production` 三种显式模式，默认 `development`。
- 只有 `demo` 允许 Mock 初始化和本地业务状态变更。
- 非演示模式 API 离线时失败并展示不可用状态。
- 生产模式写操作必须从真实认证上下文取得身份；当前未接身份平台，因此生产写入明确失败。
- 演示专属页面在非演示模式显示能力边界，不伪装成已上线模块。

## 后果

本地开发需要 API/数据库才能完整操作。production 的可信身份与职责权限后来由 [ADR 0009](./0009-external-oidc-and-application-rbac.md) 接通；OIDC 配置缺失或验证失败时仍保持失败关闭。

## 验证

前后端均有模式测试；前端测试生产模式无 Mock；浏览器分别检查演示、开发和 API 离线状态。

## 恢复

环境变量可切换回显式 `demo` 以进行演示，但不得在生产域名上使用。模式持久化键隔离，切换后需重新加载。
