# ADR-0005：运营入口与展示入口分离

状态：已接受
日期：2026-08-18

## 背景

同一导航同时放置真实订单操作、静态销量预测、数字孪生和流程展示，会让用户无法判断哪些结果可用于生产决策。

## 决策

- 一级导航围绕“今日工作、订单与客户、计划与执行、主数据”组织。
- 销量预测、数字孪生和 Showroom 放入“分析与演示”，并显示演示数据来源。
- 物料展开和生产需求属于订单/计划流程，不作为孤立一级产品入口。
- 非演示模式只开放已有真实后端支持的订单、客户、产品和配方页面。

## 后果

原型仍可完整展示，但产品边界更诚实。新增页面必须声明事实来源、写入路径和模式支持。
