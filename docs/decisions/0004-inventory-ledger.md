# ADR-0004：库存采用追加式台账

状态：提议
日期：2026-08-18

## 背景

库存余额会受到收货、领退料、产出、调拨、盘点、报废和质量冻结等并发事件影响。直接更新余额难以审计和重建。

## 决策

未来库存核心采用不可变台账事件；余额为可重建投影。纠错通过反向事件，所有事件携带幂等键和来源因果链。

## 后果

需要事务、并发控制、对账任务和投影重建工具；但能支持批次追溯与可靠审计。

## 尚待决定

- 负库存策略和锁粒度
- 成本层（移动平均/FIFO/标准成本）
- 质量冻结对可用量的投影
- 批次拆合事件语义

在这些问题解决前，仓库页面保持演示能力，不宣称生产可用。
