# UI/UX 审查

审查日期：2026-08-18；最近复核：2026-08-20
方法：桌面与移动视口走查 Dashboard、订单、配方、生产计划、MES、数字孪生、预测、Showroom 和客户门户；同时检查导航、控件行为、空/错/离线状态与数据真实性。

## 总体判断

现有视觉质量较高，具有一致的间距、卡片、表格和 Radix 交互基础；主要问题是“界面完成度”显著领先“业务完成度”，让静态指标、模拟扫码和本地状态看起来像真实生产事实。

## 已修复

- 订单中心改为主列表 + 生产交接详情：把交付紧迫度、配方覆盖、审批快照和下一步动作集中在同一决策面板。
- 生产配方升级为统一工作台：配方列表、递归逻辑表、行关系详情、标准前处理流程、配方用量试算和版本审计不再分散到多张孤立页面。
- BOM 主视图使用可展开层级表；搜索、损耗/含下级筛选、行选择、净用量、出成率、毛料、损耗和成本在同一任务面联动。移动端降级为层级卡片，不要求用户缩放画布。
- 配方页不再接收订单参数：用量试算只显示当前菜品及其递归半成品；整单物料汇总从订单详情进入，已审核订单严格读取冻结快照。
- 草稿配方支持数量、单位、出成率和物料行的增删改；已发布版本保持只读，只能复制为新版本后编辑。
- 一级导航从技术对象列表改为用户任务分组；物料展开/需求流不再占据一级入口。
- 预测、Dashboard、生产计划、MES、数字孪生、Showroom 和门户显示演示身份/数据来源。
- 非演示模式仅开放已有真实 API 支撑的客户、订单、产品和配方；其余能力显示明确边界。
- 生产模式路由改为显式白名单，动态详情只接受 UUID；订单新建、导入、审核、配方编辑和演示设置不再因宽泛前缀判断而误开放。
- API 离线时不再用浏览器状态伪造成功。
- 删除或改写无真实行为的“换一批”、签发、创建批次、联系客户等控件。
- 删除商品/客户假新建入口和物料展开页死按钮；生产订单与配方页隐藏未接通写入动作。
- 配方页新增真实版本时间线与计划发布对话框；“已发布但未来生效”显示为计划生效，不再误标为当前生效。
- 发布对话框会根据时间线上最后一个已发布版本建议下一可用时间，并解释当前版本不会提前停用、历史快照不会改变。
- “模型训练完成”“实时联动”等无法证明的表述改为静态样例/演示更新。
- 固定历史日期、假批次/工单编号改为相对演示日期和 `DEMO-` 编号。
- MES 扫码入口连接到现有演示工单，质检按钮会产生明确的本地演示反馈。
- Dashboard 指标使用已有演示数据计数，不再人为乘倍数或追加虚假数量。
- 配方页新增版本化前处理路线和阶段投料视图，验收、洗、切、低温腌制、称重组配、复核和包装按模板或自定义顺序显示，物料在实际投料步骤下归组。
- 自由缩放关系图已从日常 BOM 工作台移除；普通员工用逻辑表核对关系，用步骤导航核对前处理，不再依赖滚轮缩放和画布平移。
- 草稿编辑器可重排工序、设置工位/时长/等待/温度，并允许同一原料在不同步骤重复投入。
- 版本时间线可重新打开完整草稿定义，刷新页面后不会丢失工艺编辑入口。

## 设计方向

- Operations 首页应围绕“今天必须处理的任务和异常”，而不是图表陈列。
- MES 坚持大按钮、少文字、扫码优先和 44px 以上触控目标。
- 高密度计划/订单表格保留，因为它们支持真实比较和批量决策；避免为“现代感”牺牲信息效率。
- 展示性地图/动画只存在于分析与演示空间，不能成为工单状态来源。
- 每个正式页面都要明确覆盖加载、空数据、错误、离线、无权限和并发冲突中的适用状态。

## 浏览器验收清单

- 桌面：导航、订单审批、配方版本、长表格和对话框无截断。
- 移动：抽屉导航、关键 CTA、MES 按钮、横向表格降级可用。
- 模式：演示模式可见演示标识；开发/生产模式无 Mock；离线有明确错误。
- 交互：所有可见主按钮有真实结果或清晰解释；无空链接/死按钮。
- 可访问性：键盘焦点、对话框标题、状态播报、对比度和减少动画偏好。

### 视觉与交互优势

- 文字层级、留白、边框和低饱和状态色一致，整体接近现代运营 SaaS，而非旧式 ERP 菜单树。
- 订单、配方和工单的关键数字靠近业务对象，桌面信息密度与移动触控之间取得了合理平衡。
- 环境、数据来源与能力边界现在是持续可见状态，不依赖用户记住当前启动命令。

### 可用性与可访问性剩余项

- 移动订单状态筛选仍需横向滚动，末端标签有被截断的视觉风险；下一轮应增加滚动暗示或更紧凑的筛选方式。
- 部分浅灰辅助文字和小号元数据需要用自动对比度检查验证，不能仅凭肉眼宣称达到 WCAG。
- 尚未建立 axe、键盘全流程和稳定视觉回归门禁；当前证据覆盖人工桌面/移动走查、语义 DOM 和主交互，不覆盖全部屏幕阅读器组合。
- 生产认证仍未接通，因此生产截图只能证明只读数据和失败关闭边界，不能证明真实用户、角色和职责分离。
