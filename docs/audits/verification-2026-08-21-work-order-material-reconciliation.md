## 真实 API 业务样例

验证工单 `WO202608200005`：

1. 生产中但未领料时报产返回 `409`：“工单物料尚未按冻结配方领齐”。
2. 八类冻结叶子原料全部领齐、尚未核销时报产返回 `409`：“已领原料仍有待核销数量”。
3. 鸡胸肉净领用 `1.264 kg`，登记实际耗用 `1.200 kg`、报损 `0.064 kg`；其余原料按计划登记耗用。
4. 已耗用 `1.000 kg` 后尝试退料 `0.300 kg`，服务端返回 `409` 并明确最大待核销量 `0.264 kg`。
5. 核销完成后八类原料均满足计划、净领用和耗用/报损守恒，`reconciliation.ready = true`。
6. 实际耗用/报损没有改变库存余额；鸡胸肉余额在领料后和核销后均为 `11.236 kg`。
7. 报产成功，工单进入 `awaiting_quality`，形成待检批次 `VERIFY-USAGE-FG-20260821-001`，质量放行前没有库存入账。
8. 重复提交同一耗用幂等键返回同一事实，核销总记录数不增加。
