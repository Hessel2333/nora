# 2026-08-20 生产工单领退料验证

## 结论

首个工单物料纵向切片已完成：development 可从真实生产工单查看冻结配方叶子原料需求，选择已放行库存批次领料，并将未使用数量退回同一批次和库位。库存流水、余额 revision、工单、工位和设备上下文在同一事务中保持一致；production 在可信身份与库位权限接入前保持只读。

该能力只表示仓库发料与退料，不代表工序实际投料、消耗、产出、质检或完工入库。

## 业务验证

- 需求只从工单冻结的完整 v2 配方递归展开到叶子原料，并按工单计划量缩放、向上取整到 3 位小数。
- 领料只接受工单配方内产品、基础单位、已放行且未过期批次；不能超过剩余计划或余额。
- 退料必须回到同一产品、批次和库位，不能超过该工单对该余额行的净领用。
- 领料和退料均锁定工单与余额，检查余额 revision，并原子追加不可变流水；重复幂等键返回同一结果。
- 数据库约束要求 `source_type = work_order` 的流水绑定工单、工位、设备和匹配的来源 ID。
- 数量使用 Decimal；浏览器验收发现并修复了正零被误判为正数的问题，零数量现在在事务前拒绝，净领用归零后不再显示可退批次。
