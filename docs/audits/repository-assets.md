## 本次处理

- `.gitattributes` 将 DWG/PDF/XLSX/常见图片标记为二进制，避免无意义文本 diff。
- 未将已有文件改成 LFS 指针，因为这会改变克隆和部署依赖；也未重写 Git 历史。
- 文档明确原始材料低于可执行约束、测试、ADR 和领域契约的事实优先级。

## 建议的后续人工决策

1. 确认每个 CAD、图片、PDF、XLSX 的所有者、授权范围、来源日期和保留期限。
2. 决定大于 5–10 MB 的非运行时资产是否迁移到 Git LFS 或对象存储。
3. 若迁移已有历史，先评估 CI/部署兼容性并由仓库所有者批准；不要在普通功能 PR 重写历史。
4. 为 CAD 提取脚本记录源文件校验和、提取命令、坐标缩放和输出版本。
