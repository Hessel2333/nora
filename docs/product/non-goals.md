# 明确不做什么

首阶段刻意不承诺：

- 最终加热制作、热菜产线、热厨工位及其设备参数和制熟质量指标
- 通用财务、总账、税务、薪酬、人事与完整 CRM
- 全功能采购、供应商协同、运输管理与仓库自动化
- 真实的机器学习销量预测、自动采购决策或全自动排产
- 3D 数字孪生、设备控制、PLC/IoT 实时接入
- 自研身份平台、细粒度授权引擎或通用工作流引擎
- 通过前端本地状态模拟生产环境的成功写入
- 用当前 BOM 重新计算已审批订单的历史需求

除最终加热制作这一长期产品边界外，其余能力可作为演示、集成点或后续阶段候选，但必须在界面和文档中明确其状态。详见 [Build / Buy / Integrate](./build-vs-buy.md)。
