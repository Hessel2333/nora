# 成功指标

## 核心结果

| 指标 | 试点目标 | 取数依据 |
| --- | --- | --- |
| 从有效订单到已确认生产需求的中位耗时 | ≤ 10 分钟 | 订单与需求审计时间戳 |
| 已审批订单具备完整配方快照的比例 | 100% | `recipe_snapshot` 完整性校验 |
| 工单状态变更具有真实操作者与时间的比例 | 100% | 服务端审计记录 |
| 可从成品批次追溯至订单、工单、原料批次的比例 | 试点范围 100% | 追溯链查询 |
| 现场关键操作的任务成功率 | ≥ 95% | 可用性测试与事件数据 |

## 护栏指标

- 生产模式不允许 Mock 数据或本地业务写入。
- 同一订单重复审批不得产生重复生产需求。
- 已生效的配方版本区间不得重叠。
- 发布新配方不得改变历史审批订单的物料需求。
- 演示数据、静态预测和模拟联动必须在页面上可识别。

## 非指标

页面数量、图表数量、AI 文案数量和演示场景数量不代表产品成熟度。
