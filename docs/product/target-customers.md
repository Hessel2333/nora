# 目标客户

## 首要客户

- 具有 1 个或多个中央厨房/净配菜工厂的团餐与连锁餐饮企业
- 每日接收多个门店、食堂或客户点位的需求
- 仍大量依赖表格、微信群和人工汇总来形成生产计划
- 需要批次、保质期、质量记录和去向追溯，但现有系统割裂

## 关键用户

| 用户 | 核心任务 | Nora 首阶段价值 |
| --- | --- | --- |
| 计划员 | 汇总订单、核对配方、下达需求 | 从订单直接生成可复核的生产需求 |
| 生产主管 | 排产、分派、处理异常 | 看清任务状态与配方版本，不靠口头同步 |
| 现场员工 | 开始、暂停、完成、报异常 | 平板友好的少文字大按钮操作 |
| 品控人员 | 记录检查与不合格处置 | 将检查结果绑定到批次与工单 |
| 仓储人员 | 领料、入库、批次移动 | 用追加式台账形成可追溯库存事实 |
| 管理者 | 了解风险与交付状态 | 查看基于真实事实的运营摘要 |

## 不以其为首阶段目标的客户

- 只需要门店收银或外卖聚合的小型单店
- 首要诉求是总账、税务、人力资源的企业
- 需要一次性完成大型集团全模块替换的客户
