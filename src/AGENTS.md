# Web Local Rules

继承仓库根 [AGENTS.md](../AGENTS.md)。Web 是业务服务的客户端和任务界面，不拥有正式业务事实。

## 数据与模式

- 正式数据只经 `src/lib/nora-api.ts` 和后端取得；不要从 Mock 补齐缺失字段。
- `demo` 可使用显式本地状态；`development`/`production` 离线时必须失败关闭。
- 不在生产模式制造操作者、成功 toast、批次编号、质量结果或状态转换。
- 模式专属持久化键必须隔离，避免演示状态污染正式状态。

## 交互

- 一级入口按用户任务组织；技术对象放在流程内或二级入口。
- 可见按钮必须有真实行为、禁用原因或明确演示标识。
- 正式页面覆盖适用的 loading、empty、error、offline、permission 和 conflict 状态。
- MES 使用大按钮、少文字和触控友好间距；扫码结果必须绑定真实工单才能正式写入。
- 不把静态规则、图表或动画称为 AI/实时，除非能提供数据来源和运行证据。

## 验证

- 组件/状态测试覆盖模式隔离与关键业务交互。
- 浏览器检查桌面和移动核心路径、键盘焦点、对话框、控制台和失败状态。
- 不通过删除类型、跳过 hydration 或 suppress warning 掩盖问题。
