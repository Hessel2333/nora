# 执行、质量与追溯

计划确认并释放工单后，现场才进入可执行阶段。正式执行记录应绑定真实人员、组织、设备和服务端时间，形成可以追溯的生产事实。

## 现场执行流程

1. 扫描或选择已释放工单。
2. 按工序领料并记录实际投料批次。
3. 完成适用的质量检查与异常处置。
4. 记录实际产出、损耗、退料或返工。
5. 形成净配菜成品库存批次。
6. 通过库存流水记录入库、移库和出库。

## 当前可用的库存台账

“库存台账”已经使用正式后端记录库位、产品、库存批次、质量状态、效期、账面数量和可用数量。系统上线盘点时，仓储主管可以在 development 环境登记期初库存；同一次提交重复发送不会重复增加余额，提交后的库存流水不能直接修改或删除。

当前还不能用该页面完成采购收货、生产领料、退料、报废或成品入库。这些动作必须在后续与真实工单和质量记录连接后开放，不能用产品档案库存或浏览器进度代替。

## 质量记录

质量检查应绑定生产批次、工单或库存收发事件。发现不合格时，需要记录结果、原因和处置，不应只修改看板上的颜色或状态。

## 正向追踪

从原料库存批次出发，可以查询它进入了哪些生产批次、形成了哪些净配菜成品，以及最终交付给哪些客户。

## 反向召回

从客户订单或成品批次出发，可以反向找到相关工单、实际投料批次、供应来源和质量记录，为隔离、召回和证据导出提供依据。

## 离线与演示提示

正式现场在离线时不能假装写入成功。页面应明确显示待同步、同步失败或不可操作状态，并通过幂等记录避免重复提交。

当前 MES、工厂态势和追溯画面如果标有“演示”，只用于熟悉操作路径，不代表已经形成正式生产、质量或库存记录。
