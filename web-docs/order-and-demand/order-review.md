# 提交与审核订单

订单审核的目标不是立即安排生产，而是确认客户需求完整，并冻结后续计划可以信赖的生产依据。

## 提交前检查

- 客户和交付地点正确。
- 期望交付时间明确，能够用于选择生效中的生产配方。
- 每个商品都有清楚的数量与单位。
- 订单商品是净菜、肉类前处理品、分隔辅料或净菜组合包。

如果信息还不完整，请保留为草稿。提交后，订单进入“待审核”。

## 审核时会发生什么

审核人需要复核交付承诺、商品和数量。审核通过时，系统会为各订单行找到交付时点有效的生产配方，并保存完整的配方快照。

审核与生产需求创建是同一个动作的一部分：只有全部检查成功，订单才会变为“已审核”并得到生产需求编号。

## 审核不通过时

可以将订单退回修改，并写明需要调整的内容。常见原因包括：

- 交付时间或数量需要重新确认。
- 商品缺少有效生产配方。
- 配方中的单位无法换算。
- 配方结构不完整，无法形成可靠的物料依据。

修正后重新提交即可。重复点击审核不会创建第二张有效生产需求。

## 审核后的下一步

审核通过代表订单已经具备生产准备依据，不代表已经排产。计划员会在“生产准备”中查看新需求，再决定合批、拆分和后续工单安排。
