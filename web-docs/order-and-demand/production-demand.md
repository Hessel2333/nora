# 理解生产需求

生产需求是已审核订单与生产计划之间的承接单据。它记录“需要生产什么、多少、何时需要，以及来自哪张订单”，但它本身不是生产工单。

## 为什么先独立创建

每张订单审核通过后先创建一张独立生产需求，可以保留客户、订单行和交付承诺。计划员之后即使把多个需求合并为一个生产批次，也仍能核对每个来源的分摊关系。

这种方式也允许计划员按实际约束拆分需求，例如分日期、分工厂或分批次生产，而不会改写原订单事实。

## 在生产准备中关注什么

| 信息 | 用途 |
| --- | --- |
| 需求编号 | 查找和沟通同一张生产需求 |
| 来源订单 | 核对客户、交付时间和订单明细 |
| 计划状态 | 判断需求是否仍待处理 |
| 配方就绪情况 | 识别能否可靠展开物料需求 |
| 商品数量与单位 | 作为计划分配依据，不跨单位直接相加 |

## “待计划”代表什么

“待计划”表示需求已经形成，但尚未全部分配到生产批次。它不表示工单已经创建，也不表示现场可以开始生产。

后续可能出现“部分计划”“已计划”“已完成”或“已取消”。任何分配都必须保留原需求、已分配量和剩余量，方便计划员核对。

## 遇到配方阻断

如果页面提示配方快照不完整，请先核对来源订单与生产配方。不要用最新配方覆盖历史订单依据；修复应保留审核时的事实和清楚的处理记录。
