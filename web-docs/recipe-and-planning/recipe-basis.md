# 配方与快照

生产配方定义净配菜产品需要哪些原料、经过哪些前处理工序，以及各阶段何时投入物料。配方版本和订单快照共同保证历史生产依据不会随主数据修改而漂移。

## 配方版本

一份生产配方可以有多个版本。每个发布版本都有明确的生效时间，未来版本不会提前替代当前版本，历史版本也不会被直接覆盖。

面向用户时，重点核对：

- 成品、半成品和原料的结构是否完整。
- 数量、单位、出成率和损耗是否符合实际。
- 清洗、挑拣修整、切配、腌制、称重组配、分装、包装、复核等步骤顺序是否正确。
- 阶段投料是否绑定到正确工序。

## 订单为什么保存快照

订单审核时会按交付时间选择有效配方，并保存递归展开后的完整依据。以后即使主数据发布新版本，已审核订单和已释放工单仍然使用自己的快照。

快照能回答三个关键问题：

1. 审核当时使用的是哪一版配方。
2. 多层半成品和原料如何展开。
3. 后续物料需求与生产工单依据什么计算。

## 发现问题怎么办

草稿订单可以在修复配方后重新提交。已审核订单不能静默切换到最新版本；需要根据实际影响走明确的订单变更或冲销流程，并保留审计记录。

## 加工范围

Nora 只管理净配菜成品之前的加工。最终加热制作不进入生产配方、工序路线、工位或工单。
