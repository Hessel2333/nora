# Nora 使用帮助

Nora 把客户订单转换为中央厨房可以计划、执行和追溯的净配菜生产任务。每一步都保留来源关系，方便你核对“这批产品为什么生产、依据哪一版配方、最终去了哪里”。

> Nora 的生产流程止于净配菜成品入库，不包含炒、蒸、煮、炸、煎、烤等最终加热制作。

## 从订单到追溯

1. **提交订单**：确认客户、交付时间、商品、数量和单位后提交审核。
2. **审核订单**：系统检查交付时点可用的生产配方，并在通过时保存配方依据。
3. **形成生产需求**：每张已审核订单先形成独立需求，继续保留客户与订单来源。
4. **生产计划**：计划员根据产品、日期、工厂、产能和物料情况决定合批或拆分。
5. **释放工单**：计划确认后，才会形成供现场执行的生产批次与工单。
6. **执行与追溯**：现场记录投料、质量、产出和库存移动，并沿批次关系查询来源与去向。

## 先从哪里开始

- 需要核对生产依据时，阅读[配方与快照](./recipe-and-planning/recipe-basis.md)。
- 需要了解需求何时变成工单时，阅读[从需求到工单](./recipe-and-planning/planning-and-work-orders.md)。
