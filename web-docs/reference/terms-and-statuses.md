# 术语与状态

理解几类容易混淆的单据和状态，可以避免把“审核完成”误认为“生产完成”。

## 常用单据

| 名称 | 说明 | 不等同于 |
| --- | --- | --- |
| 销售订单 | 客户在指定时间、地点需要的商品与数量 | 生产工单 |
| 生产需求 | 从已审核订单派生，供计划员分配的需求事实 | 已排产批次 |
| 生产批次 | 针对产品、数量和日期形成的计划与执行批次 | 库存批次 |
| 工单 | 面向工序或工作中心的可执行任务 | 销售订单 |
| 库存批次 | 同源、同生产或采购事件的一组可追溯库存 | 生产批次编号 |
| 配方快照 | 订单审核时保存的完整生产配方依据 | 最新配方版本 |

## 订单状态

- **草稿**：信息仍可编辑，尚未提交审核。
- **待审核**：等待审核人确认交付与生产依据。
- **已审核**：已保存配方快照并创建生产需求，尚不代表已排产。
- **生产中**：相关需求已进入确认后的生产执行。
- **配送中**：合格成品已进入交付过程。
- **已完成**：交付事实已经完成。
- **已对账**：差异与结算依据已经确认。

## 生产需求状态

- **待计划**：尚未分配生产批次。
- **部分计划**：部分数量已分配，仍有剩余量。
- **已计划**：全部数量已分配到生产批次。
- **已完成**：所有相关分配已由执行事实完成。
- **已取消**：经过受控取消并保留原因与冲销关系。

## 环境标识

- **演示环境**：允许演示数据和浏览器内交互，页面会显示演示身份。
- **开发环境**：连接本地服务，离线或写入失败会明确提示。
- **生产环境**：只使用正式服务和真实身份；未接入的能力不会假装成功。
